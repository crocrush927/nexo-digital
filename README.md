## Premium Digital Agency Website Template

A modern, responsive and bilingual website template
for digital agencies and technology businesses.

- Modern dark design
- Persian and English languages
- Responsive mobile layout
- HTML, CSS and JavaScript
- Easy customization
- AI-inspired visual design

### Included Files
- index.html
- CSS stylesheets
- JavaScript files
- Configuration files

### Important Notes

- Testimonials are demo content.
- The contact form opens the visitor's email application.

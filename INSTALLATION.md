Installation & Customization Guide

Thank you for choosing NEXO DIGITAL!

This guide explains how to install, customize, and publish your website.

---

1. Package Contents

The package includes:

- "index.html" – Main website page
- "css/style.css" – Website styling
- "js/main.js" – Main website functionality
- "js/config.js" – Website configuration
- "js/i18n.js" – Language settings
- Additional project files and assets

---

2. Requirements

You need:

- A computer or mobile device
- A modern web browser
- A text or code editor
- Your website hosting service

No advanced programming knowledge is required for basic customization.

---

3. Installation

1. Download and extract the ZIP package.
2. Open the extracted project folder.
3. Locate "index.html".
4. Open it in a modern browser.
5. Upload the complete project folder to your hosting provider.

Important: Keep the original folder structure unchanged.

---

4. Customize Your Website

You can customize the following elements:

- Website name
- Logo
- Main headings
- Descriptions
- Colors
- Contact information
- Services
- Portfolio items
- Language content

Use the configuration files where available.

---

5. Change Website Colors

Open:

"css/style.css"

Find the CSS variables near the beginning of the file.

You can customize the background, text, violet, blue, and cyan colors.

Save your changes and refresh the website.

---

6. Language Settings

NEXO DIGITAL supports Persian and English.

The language configuration is located in:

"js/i18n.js"

Update the translations carefully and preserve the existing JavaScript structure.

---

7. Contact Information

Replace the sample email address and phone number with your own business information.

The contact form currently opens the visitor's email application. It does not provide automatic message delivery.

An additional form service is required for direct online submissions.

---

8. Hosting

You can publish the website using a compatible static hosting provider.

GitHub Pages is one possible option.

Upload all required files and preserve their folder structure.

---

9. Troubleshooting

If the website does not load correctly:

- Check that "index.html" is in the correct location.
- Check that CSS and JavaScript files are present.
- Verify that folder names and file paths have not changed.
- Test the website in another modern browser.
